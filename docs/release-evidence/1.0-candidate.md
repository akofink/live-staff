## Evidence Labels

- **Automated** means a repeatable local or CI check with browser or audio interfaces replaced where the test requires control.
- **Emulated viewport** means desktop headless Chromium rendered at specified CSS dimensions; it is not physical mobile-browser evidence.
- **Desktop browser inspection** means production or a local build was inspected in headless Chromium on the named host; it is not an attended Chrome, Safari, or screen-reader session.
- **Physical device** means an identified device and operating system were used directly by a person.
- **Historical attended** means a human attestation exported from the attended harness for a named older SHA.

The automated browser suite covers the following controlled behavior:

- Deterministic A3 analyzer samples routed to the bass staff and retained as bounded history after stop.
- Local CSV, JSON, and plain-text export of frozen stabilized history after an explicit action, without a network URL.
- Room-calibration availability and the below-threshold result with a synthetic silent stream.
- Four bounded band-stop filters, keyboard edits, bypass availability, reset, 44 CSS px remove controls, and no 320 CSS px overflow.
- Signal-monitor opt-in, no spectrum reads before opt-in, at most one read per 100 ms, one microphone request, immediate analysis stop after disable, and no 320 CSS px overflow.

- Offline continued use after initial load without a service worker, Cache Storage, or requests from listening and preference changes.

These tests establish application behavior under controlled browser objects.
They do not establish operating-system permission UI, backgrounding, screen lock, interruption, route switching, physical microphone cleanup, mobile power use, screen-reader announcement, or detector accuracy on a live source.
